# 农家乐 Agricola

网页版经典德式桌游《农家乐》（*Agricola: Revised Edition 2016*，Uwe Rosenberg 设计），支持 1 到 4 人在线联机，手机和电脑用浏览器打开就能玩。

在线体验：[farm.whiterobe.top](https://farm.whiterobe.top)

---

## 游戏特色

### 1. 还原 2016 官方修订版规则
- **十四轮回合推进**：全场共 14 轮、6 个阶段，在第 4、7、9、11、13、14 轮结束后进入收获期。
- **顺时针工人行动**：每个行动格每轮仅限一人占用。木材（每轮补 3 根）、陶土、芦苇、石材、钓鱼等随轮次自动累积；谷物与蔬菜为固定获取格。起始玩家标记可由其他人抢占，随后新一轮严格按顺时针次序轮流派人，持有标记的玩家不可连抢。
- **家园开垦与营建**：
  - 3×5 农庄空地开拓，支持木屋加盖，以及陶屋、石屋的逐级翻修；
  - 自由形状连通牧场，只要栅栏闭合，无论 L 型还是凹凸型都判定为合法牧场；
  - 圈地内建马厩可让整片牧场动物容量翻倍（每格养 4 只），空地独立马厩可养 1 只动物并免除该格的荒地扣分；农舍内自带一个宠物位，可免费寄养 1 只牲畜。
- **收获期完整闭环**：
  - 田间收割作物进入仓库；
  - 喂养家庭成员（成年人每人 2 份食物，当轮出生的婴儿仅需 1 份），口粮不足时可使用壁炉或烹饪灶紧急宰杀牲畜兑换食物，仍不足则罚发乞讨卡；
  - 同类牲畜满 2 只且有空圈时自然繁衍 1 只幼崽。
- **终局明细计分**：
  - 包含农田、牧场、各类作物与牲畜阶梯断点计分、房屋材质分、家庭人口分、马厩分、工坊建材余量分，以及荒地与乞讨扣分，每项算分依据一目了然。

### 2. 丰富的手牌与人数扩展
- **88 张经典职业卡手牌**：开局每人分发 7 张职业卡与 7 张小发展卡，涵盖农耕、畜牧、建造、烹饪、运营等不同流派。通过工人格打出，第一张职业免费，后续按规则支付口粮。
- **小发展卡构筑联动**：打出时校验前置房间数或职业数门槛并支付建材，包含即时获得物资的一次性工具与全场生效的永久收益。
- **动态行动板**：根据开局人数自动调整板面，3 人局额外补充灌木林、陶土矿、资源市场等 4 个行动，4 人局额外补充 6 个行动，多人对局不拥堵。
- **可选扩展**：支持四季交替扩展与荒野之地沼泽扩展，可在开房时按需勾选。

### 3. 原生手绘矢量风格
- **纯矢量组件绘制**：告别通用系统表情符号拼贴感。木材年轮截面、陶砖、系绑芦苇捆、凿痕石材、麦穗、胡萝卜、酸面包、木质牲畜剪影与四色木人均为独立矢量绘制。
- **中世纪版画风格大发展设施**：辘轳水井、炭火壁炉、烹饪灶、烤炉、木工坊、陶器坊、编筐坊等配有专属版画图标。
- **古典四季农事星盘**：页面背景铺设 17 世纪复古天文日历星盘，14 个罗马数字扇区直观展示当前轮次进度与丰收倒计时。

### 4. 2.5D 立体沙盘与平面视角切换
- **双视角随时切换**：支持在平铺图纸与立体沙盘之间自由切换，设置自动保存在本地浏览器中。
- **立体厚度与朝向校正**：房屋地基微抬形成厚度阴影，耕地自然下沉呈现泥垄，农田里生长的作物、吃草的动物和圈舍均立于地块之上。
- **放置与收割微动效**：工人派遣划出抛物线落入格子，资源收集飞入玩家物资栏，伴随麦浪微风吹拂与牲畜呼吸微动。

### 5. 网页物理拟真音效
- **程序化音频合成**：基于浏览器原生音频接口实时合成，无需加载额外的大体积音频文件。
- **真实桌游手感**：木块敲击桌面的沉实声、石块与陶砖碰撞的清脆泛音、农田沙沙声与丰收三和弦。随时可在悬浮菜单中一键静音。

### 6. 便捷的多端适配与辅助工具
- **手机与桌面全适配**：适配多种屏幕宽度，棋盘自适应居中缩放，横向不溢出破框；行动板按资源、常规行动、动物市场和回合卡分类分页，避免长距离翻页。
- **新手交互引导**：初学者可跟随指引高亮查看工人格说明与农场建设路径，支持随时退出。
- **右下角快捷工具球**：
  - 实时榜单：随时查看全场排名与详细算分构成；
  - 流派打法：提供农耕、畜牧、造房添丁等主流路线说明；
  - 物资速查：随手查看建筑造价、牲畜容量上限与烹饪兑换比例；
  - 规则手册：全中文精简规则与扩展说明。
- **4 位纯数字房间码**：进房、观战与邀请均使用 4 位数字，手机输入法直接敲数字即可进房，无需复制复杂长链接。

## 系统架构与工程目录

### 1. 架构示意图

```text
                       ┌──────────────────────────────────────────────┐
                       │          Cloudflare Edge Network             │
                       │        (Workers + Durable Objects)           │
                       └──────────────────────┬───────────────────────┘
                                              │
              ┌───────────────────────────────┴───────────────────────────────┐
              ▼                                                               ▼
   ┌───────────────────────┐                                     ┌─────────────────────────┐
   │     静态资源服务      │                                     │     Worker 接入层       │
   │  HTML5 / CSS3 / ES-M  │                                     │   REST API + WS Gateway │
   └───────────────────────┘                                     └────────────┬────────────┘
                                                                              │
                                             ┌────────────────────────────────┴────────────────┐
                                             ▼                                                 ▼
                                  ┌────────────────────┐                            ┌─────────────────────┐
                                  │    Registry DO     │                            │       Room DO       │
                                  │ (全局单例注册中心)   │                            │ (每个房间独立实例)  │
                                  │ - 房间池分配与仲裁   │                            │ - WebSocket 睡眠唤醒 │
                                  │ - 4位纯数字匹配路由  │                            │ - 状态存储与事件广播 │
                                  └────────────────────┘                            └──────────┬──────────┘
                                                                                               ▼
                                                                                    ┌─────────────────────┐
                                                                                    │  src/game/engine.ts │
                                                                                    │  核心游戏规则状态机  │
                                                                                    └─────────────────────┘
```

- **接入与路由**：Cloudflare Workers 负责静态页面分发与 WebSocket 网关代理。
- **状态存储与长连接**：基于 Cloudflare Durable Objects，利用休眠唤醒机制保持 WebSocket 会话，房间空闲时自动休眠以节省资源。
- **核心逻辑**：纯 TypeScript 编写的规则状态机，所有行动校验、牧场连通判定、顺时针轮替和终局计分均在服务端独立执行。
- **前端实现**：原生 JavaScript 模块化开发，不依赖第三方大型前端框架，图形与音效均使用浏览器原生能力。

## 本地开发与测试

运行环境建议使用 Node.js 20 及以上版本：

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务（运行在 http://127.0.0.1:8787）
npm run dev

# 3. 运行代码类型检查与全量规则测试（包含 310 项断言）
npm run typecheck
npm test
```

本地启动后，可用两个不同的浏览器标签页或无痕窗口分别进入游戏房间，验证联机与顺时针轮流行动。
