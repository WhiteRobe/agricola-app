# 农家乐 Agricola

网页版经典桌游《农家乐》（*Agricola: Revised Edition 2016*，Uwe Rosenberg 设计），支持 1 到 4 人在线对局，用浏览器打开就能玩。

在线体验：[farm.whiterobe.top](https://farm.whiterobe.top)

---

## 玩法与规则还原

游戏按 2016 年官方修订版规则实现：

- **完整 14 轮推进**：分 6 个阶段逐步揭示新行动，包含第 4、7、9、11、13、14 轮的 6 次收获期。
- **工人放置**：每轮每格行动互斥占用；木材（每轮 3 根）、陶土、芦苇、石材、钓鱼等累积格按轮次自动补充；谷物与蔬菜为固定获取格。
- **顺时针轮换**：起始玩家标记可抢占，新一轮严格按顺时针次序轮流放置工人，已持有标记的玩家不可重复抢占。
- **农场开拓**：
  - 3×5 个人农庄网格，包含木屋扩建、半木陶屋与石屋升级翻修；
  - 自由形状连通牧场，支持 L 型、凹凸型等任意闭合围栏；
  - 圈地内建马厩可让牧场容量翻倍（每格 4 只），荒地独立马厩可养 1 只动物并避免荒地扣分；
  - 农舍自带宠物位，可在屋内免圈养殖 1 只动物。
- **手牌构筑与扩展模式**：
  - 开局每人发 7 张职业卡与 7 张小发展卡，对局中消耗资源或满足门槛打出；
  - 支持 3 人局（额外增加 4 格行动）与 4 人局（额外增加 6 格行动）官方版图动态伸缩；
  - 支持四季扩展与沼泽扩展按需开启。
- **收获结算与终局计分**：
  - 田间收割、食物喂养（不足时转入临时烹饪或扣乞讨卡）、成对牲畜繁衍；
  - 13 维明细计分面板，准确计算农田、牧场、各作物与牲畜阶梯分、房间分、马厩分、工坊建材余量加分与未利用荒地扣分。

## 本地运行

项目运行在 Node.js 环境下（建议 Node 20+）：

```bash
# 安装依赖
npm install

# 启动本地服务
npm run dev

# 运行规则测试
npm test
```

本地服务默认跑在 `http://127.0.0.1:8787`，用两个不同的浏览器标签页或无痕窗口打开即可测试双人联机。

## 部署

项目配置适配 Cloudflare Workers 与 Durable Objects：

```bash

```
